PIGEON EYE · QUEST HUD (WebXR fallback v0.1.0)

Passthrough HUD with a compass tape and a heading-up minimap (your path, waypoints, cleared rooms). There's no camera detection here because browsers can't read the Quest camera; use the APK for that.
Controls: Trigger = waypoint, Grip = MARK CLEAR, A/X = SET NORTH (face north first).
Everything runs locally in the browser and nothing is uploaded.
